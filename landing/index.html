AGENT WORKFLOW MATRIX

AI Agent Slash Commands

Execute structured security reviews at every phase of your software development lifecycle.

Command Phase Description
/sr-audit Milestone / Release Full-system whitebox security review and comprehensive OWASP assessment.
/sr-staged Pre-commit Focused review of changes currently staged in Git (git diff --cached).
/sr-branch Feature / PR Reviews security risks introduced by feature branch diffs against destination base.
/sr-plan Design Phase Audits technical plans for missing trust boundaries and attack vectors.
/sr-tasks Strategy Phase Ensures security requirements are sequenced properly in implementation tasks.
/sr-followup Triage Transforms security findings into structured remediation tasks.
/sr-apply Remediation Applies approved security refactors directly to tasks.md and plan.md.
/sr-export Compliance Generates formal Executive and Technical Pentest Reports.
/sr-verify Verification & PoC Re-verifies findings, tests exploitability, and generates safe PoC reproductions.
/sr-init Initialization Initializes or refines the project security constitution.
