# AI Agent Skills & Workflows

> How to integrate and execute Security Review skills across AI coding agents (Antigravity, Claude Code, Cursor, OpenCode, Codex).

---

## 1. How AI Agents Use Security Review

Security Review provides **token-optimized developer acceleration** for AI agents:
1. **The CLI is the Accelerator**: Fast git diff extraction (`security-review diff`), security entrypoint scanning (`security-review scan`), and YAML frontmatter validation (`security-review validate`).
2. **The Agent is the Reasoning Brain**: The LLM analyzes the formatted context, reasons through architectural boundaries and threat models, and outputs structured findings.

---

## 2. Standalone Agent Slash Commands

When working with an AI coding assistant, use the canonical standalone slash commands:

| Slash Command | Purpose | When to Use |
|---|---|---|
| `/security-review` | Full-repository security audit | Milestone reviews, release audits, brownfield onboarding. |
| `/security-review.staged` | Staged changes review | Pre-commit check (`git add`). |
| `/security-review.branch` | Branch / PR diff review | Feature branch development vs. base (`main`). |
| `/security-review.plan` | Technical plan review | Architecture design phase before tasks are generated. |
| `/security-review.tasks` | Implementation tasks review | Task breakdown phase before coding. |
| `/security-review.followup` | Findings to tasks conversion | Converting security findings into structured tasks. |
| `/security-review.apply` | Apply approved refactors | Updating `tasks.md` and `plan.md` automatically. |
| `/security-review.export` | Formal pentest report | Executive & Technical synthesis export. |
| `/security-review.init` | Security constitution init | Establishing security rules during project onboarding. |

---

## 3. Token-Budgeted Context Injection

Agents can run `security-review diff` to extract only security-relevant changes, keeping token consumption minimal:

```bash
# Markdown table formatted for LLM context (default 8,000 token budget)
security-review diff --staged

# JSON payload for subagents
security-review diff --branch feature/auth --json --budget 4000
```

---

## 4. Structured Report Output & Memory Routing

Every security review generated by an AI agent outputs a standardized YAML frontmatter header:

```yaml
---
document_type: security-review
review_type: branch
assessment_date: "2026-08-19"
overall_risk: HIGH
total_findings: 4
critical_count: 1
high_count: 2
medium_count: 1
low_count: 0
owasp_categories: [A01, A03, A07]
---
```

This frontmatter allows memory indexers and fast grep lookups to route findings without reading full Markdown reports.
